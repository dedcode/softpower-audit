Method, reproducibility & limitations

The full January 2025 candidate pool was extracted from GDELT GKG. There is no row cap. Each day/URL is counted once. For a distinct monthly URL, detected locations are combined across its matching daily records; if any of those records includes an extra country, that URL fails the “only pair” filter. This is conservative for pages updated during the month. Raw location strings are preserved in the local research package.

A specific Kenyan place uses GDELT location type 4 (city or landmark) or 5 (first-level administrative region), with country code KE. Multiple places in the same country still count as one country. Unknown geographic codes remain in the country set, so the “only pair” test does not silently drop them. Distinct URLs are not necessarily distinct stories; syndication and duplicate URLs remain possible. The first observed date is not a verified publication date.

The review is an assistant-read qualitative check across publisher groups and geography categories, spread across websites. It is not a random sample or an estimate of classification precision. Unavailable and blocked pages are reported separately. No filters establish audience exposure or prove a soft-power strategy.
